# Pepsi Cola ERP — Case Study

## Overview
An internal ERP module for sales and purchase workflows, built on the .NET stack and Azure.

## My Role
I worked on it as a Software Engineer (02/2020 – 01/2021), on site:
- Upgraded the legacy **.NET Framework 3** codebase to **.NET 8** and aligned it with modern coding standards
- Resolved bugs and errors in **Azure Functions**
- Implemented the **Unit of Work** pattern with ADO.NET to manage database operations and keep transactions consistent
- Designed secure, high-performance RESTful APIs and improved endpoint security
- Fixed critical bugs in sales and purchase reports and optimized complex SQL procedures for faster report generation

## The Problem
Sales and purchase reports were slow and error-prone, and the old codebase was hard to maintain.

## The Solution
Modernized the platform to .NET 8, made database work transactional with Unit of Work, and tuned the SQL behind the reports.

## Tech Stack
- **Backend:** .NET Framework 3 (legacy), .NET 8, Minimal APIs, RESTful APIs
- **Data access:** ADO.NET, SQL procedures
- **Cloud:** Azure Functions, Azure

## Key Features
- Sales and purchase workflows
- Faster sales and purchase reports
- Transactional data access with Unit of Work
